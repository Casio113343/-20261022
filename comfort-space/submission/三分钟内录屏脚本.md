# 栖语使用流程录屏脚本

建议时长：2 分 45 秒；硬上限为 3 分钟。文件建议命名为 `栖语_第二次作业_使用流程.mp4`。

这是录制脚本本身，实际视频已另外提供为同目录 MP4（2 分 28.5 秒、无声字幕版）。视频使用真实网页操作画面分段采集后拼接。

## 录制前

按 `comfort-space/README.md` 启动 PostgreSQL、Scala 后端和前端，浏览器打开 `http://127.0.0.1:5173/`，确认页面显示“后端演示”。只录网页区域，不打开凭据文件。建议选择 1280×720、30 帧、H.264 MP4，视频码率约 2–3 Mbps；实际以导出后的文件大小为准。

## 操作和解说

| 时间 | 操作 | 可直接使用的解说 |
| --- | --- | --- |
| 0:00–0:10 | 展示首页标题、倾诉入口与导航 | 这是栖语，一个情绪陪伴前后端系统。用户可以直接开口，不需要先给问题分类。 |
| 0:10–0:55 | 依次输入下方四句，展示每轮回复 | 系统先接住情绪，不连续追问。交流几轮且线索足够后，后台调整后续陪伴方向，保持同一段对话。当前展示的是服务端演示模板，并非真实大模型。 |
| 0:55–1:10 | 刷新聊天页，再进入“往日对话”，点击继续 | 消息通过 Scala 后端保存到 PostgreSQL。刷新后仍可恢复，并且按访客身份隔离。 |
| 1:10–1:30 | “拾一句温柔”收藏一张卡片，再打开“收藏的微光” | 用户可以挑选安慰卡片并收藏，收藏记录也会保存到数据库。 |
| 1:30–1:50 | “心情手记”选择心情，填写一句备注并提交 | 心情手记可以记录当下感受，保存后能够继续查看或删除。 |
| 1:50–2:05 | “安静片刻”开始、暂停、重置 | 不想说话时，可以使用一分钟呼吸提示，随时暂停，不强迫完成。 |
| 2:05–2:20 | “我的偏好”展示称呼、减少动态、导出和清空按钮 | 用户可以设置偏好、导出自己的记录或清空内容。数据库操作具备事务与失败重试机制。无需在录屏中清空已有内容。 |
| 2:20–2:35 | 依次打开“关于栖语”和“隐私与数据” | 网站明确说明演示范围、数据保存位置和访客身份期限，不把模板回复冒充真实 AI。 |
| 2:35–2:45 | 回到首页或停留在项目源码目录 | 前端采用 TypeScript 和 React，后端使用 Scala 3 与 IO。完整源码、测试及启动说明随附件提交。 |

聊天输入示例（均为合成演示内容）：

1. 今天考试成绩不理想，我有点失落。
2. 我为学习准备了很久，还是没达到期待。
3. 我一直很在意这次考试，觉得有点委屈。
4. 谢谢，我想先慢慢缓一缓。

手记示例：`今天给自己留一点休息时间。`

## 导出与提交

1. 播放最终视频，确认首尾完整、文字可读，时长不超过 180 秒。
2. 检查源码 ZIP 加视频的总大小小于 100,000,000 字节；视频过大时降低码率或缩短等待，不删减源码。
3. 将源码 ZIP 和实际 MP4 视频作为附件上传。答案说明可复制同目录《作业说明.md》中的正文。
4. 本 MD 文件不是视频附件；请上传已经生成并检查过的 MP4。
