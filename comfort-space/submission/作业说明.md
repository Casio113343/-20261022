# 第二次作业：栖语——情绪陪伴前后端系统

## 可粘贴到“答案说明”的内容

项目名称：栖语——情绪陪伴前后端系统。

本项目提供约十个功能页面，包括倾诉首页、连续聊天、往日对话、安慰卡片、收藏、安静片刻、心情手记、个人偏好、关于与隐私说明。用户进入后可以直接倾诉，系统先回应情绪，经过几轮交流且线索足够后，在后台调整陪伴方向，不要求先分类或填写问卷。

前端采用 TypeScript、React、Zustand、Tailwind 和 Vite；后端采用 Scala 3、Cats Effect IO、http4s、Circe 和 PostgreSQL。代码以纯函数核心和不可变数据为基础，副作用通过明确边界执行。后端按照模块化单体、消息式 API 和公开表方法组织，实现访客会话隔离、消息持久化、幂等重试、事务回滚，以及收藏、手记和偏好的增删改查。刷新页面或重启服务后，可通过同一有效访客身份恢复已保存内容。

当前版本使用明确标注的服务端演示回复与关键词方向规则，未接入真实大模型，不提供专业心理诊断。已通过 16 项后端测试、9 项前端测试，以及前端类型检查和生产构建，并完成浏览器与真实 PostgreSQL 联调。

源码附件包含运行配置、数据库初始化、前后端代码、测试、启动脚本及说明。首次运行需要安装或下载依赖，具体步骤见压缩包内 README。
