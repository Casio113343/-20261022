# 栖语：架构与实现边界

更新：2026-10-29。当前已由浏览器演示升级为本机前后端演示，仍不调用真实模型。

## 结构

```text
comfort-space/
  frontend/src/
    apis/<service>/        与后端消息对应的类型化 HTTP 调用
    system/api/            命名、传输、超时、错误、响应校验
    domain/                不可变类型与纯 UI 状态转换
    state/                 Provider 私有 Zustand 与请求生命周期
    components/ui/         跨页面基础组件
    components/Layout.tsx  导航、状态提示与页面外壳
    pages/<Page>/          页面业务视图及局部状态
  backend/src/main/scala/services/
    identity/              访客身份、偏好、本人数据快照与清空
    conversations/         会话归属、消息顺序、版本、幂等请求
    companionship/         入口及专门方向的演示回复
    routing/               纯方向评估规则
    journal/               心情手记
    collection/            收藏
    system/                API 注册与路由、连接生命周期、事务和启动
  backend/src/test/scala/   规则、HTTP 和真实 PostgreSQL 测试
  scripts/                 开发工具准备与数据库启停
  docs/                    网站当前文档
```

业务模块按 `api/objects/routes/tables/utils` 的真实职责使用目录，不创建无用空层。system 的 `api/` 和 `database/` 分别负责消息基础设施及资源/事务，不是额外业务服务层。

## 两个案例的借鉴

沿用教学系统的业务闭环与 LOCUS 的模块化单体；按本项目修订规章统一为独立消息类、`plan(connection): IO[A]`、公开表方法、独立表初始化和前端 API 对应文件。不把示例实现全部视为正确，也不为十页作业拆成多个独立部署服务。

## P_0 函数式约束

- Scala 领域数据为不可变 case class，角色与方向为闭合 enum。纯回复和方向规则只读取显式传入的 Conversation 和阈值。
- 时间与随机 ID 在消息的 IO 边界取得，数据库访问返回 IO；通过 Resource 管理语句、结果集、连接和连接池。
- 所有业务状态存于有归属的 PostgreSQL 表；没有模块级可变用户、消息、缓存或会话计数器。
- 每个 API 在独立文件中，以 plan 为公共执行入口；路由解析请求与可信身份，不接收前端自报的可信 userId。
- SQL、参数绑定、行映射只在所属表方法中封装；初始化各表独立。开发数据库创建属于 system 基础设施，不是业务 API。
- 事务统一 commit/rollback，错误和取消均回滚。访客行锁与会话版本检查解决并发；不依赖单进程内存锁。
- React 使用 Provider 私有 Zustand；纯 reducer 不读取 Store。API、Cookie 认证和响应校验在显式边界，派生列表不重复维护。
- 连接请求句柄由 Provider 按生命周期持有，避免 StrictMode 重复创建访客；它不作为业务会话存储。前端不再生成回复或判断方向。

## 本轮消息流

1. 路由通过 Cookie 解析服务端访客身份。
2. 短事务取得访客行锁，核查请求编号和会话归属。
3. 纯模板按上下文生成演示回复；完成本轮后纯规则判断是否调整方向。
4. 原子写入消息、方向、版本与幂等关联；成功提交后返回服务器会话。
5. 前端用服务端消息替换乐观显示，失败则保留请求编号供重试，不用假回复掩盖故障。

当前回复不含网络 I/O，故可在一个短事务内完成。接真实模型时必须改为分阶段事务和可恢复请求状态；本轮没有声称已实现外部模型预约队列、流式输出或断线续传。

## 数据与视觉

内容转为本机后端数据库保存，界面和隐私说明已同步修改。旧 localStorage 不自动上传。访客固定七天失效，启动和每小时清理过期数据；本机数据库管理者仍可能读取内容。

视觉保留米白、鼠尾草绿和静态叶片，不使用旧视频。Tailwind 为样式主体，自定义 CSS 仅为入口、字体、焦点和减少动态覆盖。

## 未完成的后续范围
