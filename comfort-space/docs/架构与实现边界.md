# 栖语：架构与实现边界

## 本轮范围

用户已选择先完成演示模式。本轮产物是十个页面的可运行前端；没有冒充真实 AI、后端接口、账户认证或数据库落库。页面数按功能页面统计，对话详情与 404 不另计。

## 目录职责

```text
comfort-space/
  frontend/
    src/
      domain/              不可变类型、纯状态转换、纯演示回复与方向规则
      state/               Provider 私有的 Zustand Store 与异步编排边界
      system/              浏览器存储、下载等副作用适配器
      data/                静态文案常量
      components/ui/       跨页面基础 UI
      components/Layout.tsx 网站导航外壳
      pages/<Page>/        各页面的业务视图与局部状态
    package-lock.json      依赖锁定
  backend/README.md        Scala 后端实施边界与下一阶段
  docs/                    本网站说明与验证记录
```

`Layout` 仅组织导航、页头、页脚和 Outlet，具体业务区域直接显示在各页面入口。当前页面逻辑较小，不创建无用途的多层目录；复杂后再就近拆分 Hook 和区域组件。基础组件归入 `components/ui/`；`components/Layout.tsx` 是共享导航外壳，不放页面专属业务。

## P_0 函数式落实

- `appReducer(state, action)` 返回新状态，禁止修改旧消息数组；ID、时间从事件或定时器边界取得后传入。
- `demoReply(conversation)`、`assessDirection(conversation, minimumTurns)` 只计算，不访问 Store、DOM、网络或浏览器存储。
- Store 由 React Provider 实例持有，不设可变模块单例。`useApp` 订阅受控状态；快照读取仅在发送事件边界；`setApp` 经纯 reducer 更新。
- 搜索结果、收藏列表、会话轮数和呼吸提示由现有状态派生，不重复保存副本。
- 存储与下载放 `system/storage.ts`，定时器清理和持久化位于 Effect 边界。渲染不进行写入。
- 延迟回复携带 requestId，过期结果不能恢复已删除会话；等待期间禁止重复发送。
- IO / Monad 与事务规则适用于下一阶段 Scala 后端，本轮未写伪后端来宣称完成它们。

## 借鉴两个案例

借鉴教学系统与 LOCUS 的领域分组、清晰页面职责和可追踪消息链。正式后端沿用模块化单体，不为十页作业强拆多个部署服务。当前浏览器演示并不等于已完成案例的消息式后端架构。

正式服务按 `companionship`（对话与策略）、`journal`（手记）、`collection`（收藏）、`account`（身份）、`system`（配置与连接生命周期）归属组织。边界随需求实施，不提前生成空文件树。

## 视觉与无障碍

米白、鼠尾草绿、中文衬线标题；静态叶片由 Tailwind 构成，无外部视频与远程素材依赖。自定义 CSS 仅保留 Tailwind 入口、字体主题、基础焦点样式及跨页面的减少动态覆盖。表单具有标签、等待状态与禁用状态；导航在窄屏折叠。页面小号文字按最深卡片底色调整对比度，系统与用户减少动态偏好均生效。

## 后续完成作业的必要工作

1. Scala 3 + Cats Effect IO + http4s / Circe 的消息式 API；PostgreSQL 的公开表方法与独立初始化。
2. 明确访客或账户身份、会话归属、事务、并发版本、失败恢复和删除语义。
3. 用户选定真实模型后，在后端读取环境配置接入；不得把密钥放前端或 Git。
4. 实现真实情绪回应和后台策略切换，补充错误、超时、取消与安全分支验证。
5. 前后端联调、约十页验收，录制不超过三分钟使用流程；打包完整源码，总附件不超过 100 MB。
