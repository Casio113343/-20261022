# 栖语 · 安慰网站演示版

本文件夹独立容纳新网站的代码、配置和开发文档。课程资料与原项目历史文档继续留在仓库原位置。

## 当前完成范围

本阶段按用户选择完成**浏览器本地演示**：TypeScript + React + Vite + Tailwind + Zustand。没有真实模型调用，没有服务器存储，也没有登录功能。预设回复会明确显示“演示回复”。这不是第二次作业的最终完整前后端交付。

| 页面 | 路径 | 可操作内容 |
| --- | --- | --- |
| 此刻，停靠 | `/` | 输入心事、快捷开场、收藏卡片 |
| 聊一会儿 | `/chat`、`/chat/:id` | 连续消息、等待状态、重新开聊 |
| 往日对话 | `/history` | 搜索、继续、确认删除 |
| 拾一句温柔 | `/library` | 按标签筛选、收藏与取消 |
| 收藏的微光 | `/saved` | 查看与取消收藏 |
| 安静片刻 | `/quiet` | 一分钟呼吸提示、暂停、重置 |
| 心情手记 | `/mood` | 记录心情、备注、删除 |
| 我的偏好 | `/settings` | 称呼、本机保存、减少动态、导出、确认清空 |
| 关于栖语 | `/about` | 产品说明、演示边界 |
| 隐私与数据 | `/privacy` | 保存位置、数据选择、删除方式 |

## 启动

需要 Node.js 22.12+（当前验证环境 Node.js 24）。

```powershell
cd comfort-space/frontend
npm ci
npm run dev
```

浏览器打开 `http://127.0.0.1:5173/`。默认仅绑定本机。该地址需要本地服务运行，不是已发布公网地址。

```powershell
npm test
npm run build
npm run preview -- --host 127.0.0.1
```

部署静态构建时需配置所有页面路径回退到 `index.html`，以支持 BrowserRouter 的深链接。不要上传 `node_modules`、`dist` 或本地对话导出文件。

## 对话原则

先回应感受，不要求选择问题类型。演示前两轮不判断方向，第三轮回复完成后，有足够且不冲突的关键词才在后台记录方向，后续回复沿用上下文。三轮只是演示参数；真实模型接入时应根据交流充分程度判断，不把次数变成对用户的任务。

演示模板数量有限，会出现重复，不等于真实 AI 理解。遇到高风险关键词时显示通用安全提示；关键词规则可能漏检或误检，不能作为可靠危机识别系统。

## 数据选择

默认仅内存保存。开启本机保存才使用 localStorage；关闭会移除存储副本。导出为用户本地 JSON。刷新期间未完成的回复不会恢复。浏览器存储失败或内容超出本地保存上限会显示提示。本机保存不等于加密存储。
