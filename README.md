# 前后端

基于《2026-无代码零基础软件制作》课程整理的前后端开发项目资料。

GitHub 目标账号：[Casio113343](https://github.com/Casio113343)。用户期望仓库名称为“前后端”；实际远端名称及链接待 GitHub 创建成功后记录。

## 项目文档

- [编码规章制度](./本项目编码规章制度.md)：按 P_0、P_1、P_2 整理语言、函数式编程、网页开发和工程规范。
- [编码指令入口](./AGENTS.md)：后续编码及同步要求。
- [资料归档清单](./docs/资料归档清单.md)：原始资料、提取文字与核验范围。
- [仓库同步说明](./docs/仓库同步说明.md)：同步方式和当前状态。

## 技术方向

前端使用 TypeScript + React，后端使用 Scala 3，遵循纯函数核心、副作用边界和 Monad / IO 组合的课程方案。

当前目录主要包含课程资料和规章文档，尚未创建可运行的前后端应用。
