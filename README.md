## 技术方向

前端使用 TypeScript + React，后端使用 Scala 3，遵循纯函数核心、副作用边界和 Monad / IO 组合的课程方案。

当前产品为多类型游戏生成平台，新工程位于 [game-workshop](./game-workshop/README.md)。后端已加入素材任务、加工与版本复用机制，前端仍在开发；见 [后端说明](./game-workshop/backend/README.md) 和 [验证记录](./docs/后端首轮验证记录.md)。
