## 运行步骤

需要 Windows、PowerShell 7、Node.js/npm 和网络。将 ZIP 解压至可写目录，进入解压根目录：

```powershell
./game-workshop/scripts/setup-tools.ps1
./game-workshop/scripts/start-database.ps1
./game-workshop/backend/run.ps1 -Tasks @('test')
./game-workshop/backend/run.ps1 -Tasks @('runMain services.system.Main')
```

另开终端：

```powershell
cd game-workshop/frontend
npm ci
npm run dev
```

访问 http://127.0.0.1:5173 。项目首次启动会下载 JDK、sbt 与 PostgreSQL，可能耗时。数据库表由 Scala 初始化程序建立，非人工遗漏 SQL。数据库密码在首次初始化时本地生成；包内不含真实密码、令牌或模型密钥。

## 页面

工作台 /studio，作品 /projects，制作 /production/:id，试玩 /play/:id，资源库 /library，以及 /character、/world、/skill、/asset、/edit、/promo 六个独立服务，共11类页面。制作和试玩页依赖先保存作品并满足状态条件，不是独立空白展示页。

## 当前真实能力

已实现资料保存、方案整理和确认、六类独立成果保存、资源版本化及工作台选用，美术任务和版本管理；后端独立 AI 生成支持候选、确认、重试和私有访问。23项前端和30项后端测试此前通过。

真实模型未配置，前端生成按钮尚未接线；不能声称已经完成任意游戏生成或真实AI绘图。游戏运行器为本地简化模板，必须具备图片绑定才能进入试玩。生成网关是项目自定义协议，不是任意供应商API直接兼容；详见 docs/独立服务AI生成后端.md。
