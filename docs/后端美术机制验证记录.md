# 后端美术机制验证记录

日期：2026-10-31。

验证命令：`game-workshop/backend/run.ps1 -Tasks @('test')`。

最终运行结果：27项通过，0失败。覆盖17项纯业务规则、2项真实图片加工检查、8项PostgreSQL/HTTP集成检查。测试图片由测试目录中的专用替身创建，生产入口不使用该替身。

## 核验范围

- 新游戏按本次设定建立美术任务；重复请求不重复生成。
- 修改规则和名字后，原图ID、成品ID、素材版本和SHA-256保持一致。
- 明确改图只更新指定槽位，提供旧原图与修改说明；未提及的素材保持一致。
- 新增人物只新增对应任务；失败只重试失败项，不重画成功素材。
- 美术原图与加工后的PNG独立保存；原始字节不变，角色成品尺寸384×384，透明通道保留；非法图片被拒绝。
- 素材版本恢复、原型配置快照读取、过期任务结果拒绝覆盖。
- 私有作品与任务的访问隔离。
- 未配置图片服务时返回等待配置/阻塞，不能登记伪造的生成成功。
- HTTP分阶段执行：测试替身在图片服务阶段重新取得同一作品的数据库锁，验证原事务已经释放；重复制作不会再次调用成功素材的图片服务。

## 验证限制

没有调用真实图片模型，未验证其生成质量、人物一致性、局部编辑效果或调用费用。没有进行本轮前端联调、图形运行器加载、完整游戏可玩性或生产部署验收。

真实图片提供方依旧留待后续选择和接入；后端当前默认使用未配置提供方，保留任务并明确提示未完成。

构建、测试均以实际本地执行结果为准；PostgreSQL为项目专属本地开发实例。
