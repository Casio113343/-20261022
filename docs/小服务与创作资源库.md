# 小服务与创作资源库

新增六类独立服务：角色设计、世界观工坊、技能与卡牌设计、游戏素材制作、美术修改、宣传物料。入口为 /services，成果集中在 /library，可编辑、按版本保存、搜索和分类。

工作台新增资源连接区：先保存游戏草稿，再选择成果、确切版本和接入位置。世界观替换世界观；人物可新增或替换指定人物；技能及制作说明接入玩法要求；宣传资料保存为展示关联。接入会使旧方案失效，需要重新审阅确认。资源库产生新版不会自动覆盖游戏，连接区提示并允许明确更新。

制作页美术历史可将生成素材保存为资源。仅后端核实归属的生成原图与加工图可以作为正式美术复用；上传参考图不等同于生成素材。图片接入仅允许匹配现有美术位置的用途，不兼容时拒绝并提示另行加工。接入指定位置会保留其他美术，过时任务不能覆盖新选素材。

后端新增 library 领域、资源版本表与项目连接表。API 包括 ListResources、GetResource、SaveResource、AttachResource、ListProjectResources，使用访客身份、事务和乐观版本校验。连接记录保存资源来源，工作台后续手工修改独立保存。

当前真实图片和自由创作模型尚未接入，小服务可编辑保存需求与设定、复用已有生成成果，不能宣称已具备独立 AI 绘图或任意技能编译能力。小服务编辑页尚无自动草稿恢复，离开前应保存。

验证：前端构建通过，23 项既有测试通过；后端编译与27项既有回归通过。新增真实 HTTP / PostgreSQL 联调验证了保存、世界观接入、资源更新后游戏仍固定旧版本、其他访客资源列表隔离。新增图片跨项目复用与各类服务的浏览器交互尚未全面验收。
