## 不直接照搬的部分

- 图书模板的部分公开表能力仍为服务内可见，与 R6—8 不一致；本项目按需公开封装好的方法，保留私有 SQL。
- 示例中的 `for ... yield` 是 IO 组合语法，不能简单等同命令式循环。本项目新业务仍默认 map / flatMap。
- 表底层的 JDBC `try/finally`、while 和可变构建器不作为纯业务写法模板。
- 前端通过 `constructor.name` 推导路由须考虑生产压缩，不能只证明开发时正常。
- 不因教学案例使用 Kafka、Redis、MinIO 就全部引入本项目，也不因 LOCUS 接入地图或付费 AI 就增加这些外部依赖。
- 不复制案例作者的身份资料、真实密钥、默认管理员凭据或无关工程缓存作为项目交付内容。
