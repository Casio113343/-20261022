## 三、主题和视觉方向

网站定位是“安慰网站”的封面。核心表达：

> 每个人有两双眼睛，一双看清世俗的琐碎，另一双看透内心的美好。

借鉴用户提到的 Crisco 夜光绘画中“亮时看到现实，暗时发现美好”的表达方式。核心交互是开灯、关灯，同一场景在熄灯后呈现隐藏的想象，而不是普通的日夜换图。

视觉要求：成熟、新颖、立体、自然，有动态。不要幼稚卡通感，不要油画色彩，不要恐怖、幽灵或女鬼感，不要无缘由的粉色光晕和炫光。

人物与主要场景在左侧，右侧留给文字和开关。保留早期精细、轻盈、发光且有羽翼轮廓的鸟。

## 四、当前故事和状态顺序

### 1. 开灯状态

- 成年人物坐在桌前，灯亮着，动态写字。
- 笔与手自然地从左向右书写，不能只有上下抖动，也不能表现为从上到下写。
- 地面废纸团使用用户选定的三张纸团构型。纸团褶皱或轮廓可以隐约像鸟，但仍是废纸。
- 不要给纸团加鸟眼睛、鸟喙、头脸、脚等动物器官。

### 2. 关灯过程

1. 用户按开关，旧字幕先隐去。
2. 人物做出关灯动作。
3. 右侧光影在人物实际开关灯的同时变化。需要柔和过渡，但不能从点击按钮时就提前开始，也不能滞后于灯的变化。
4. 人物停止写字，双臂放在桌上，头完全趴稳，呈现短暂休息、睡觉的状态。
5. **只有完全趴稳后**，才开始出现鸟影与相关丝线。

不能在黑暗中继续写字，也不能在人物还没趴好时提前出鸟。

### 3. 鸟影显现与起飞

- 最新明确的起点是**地面那三个废纸团**。早期曾提及桌面纸团，后续要求已明确改为下方地面纸团，应以后者为准。
- 鸟影沿纸团现有的鸟形轮廓、折痕逐渐显现，再脱离纸团飞出。
- **纸团本体始终保持原位和原形**：不能移动、抬起、展开、变形、变成鸟、飞走或消失。
- 鸟离开后，原来的纸团仍留在地面。
- 只发生一轮显现和起飞，不能突然再来第二批鸟。
- 鸟应向左侧窗外飞，鸟头朝左。不能掉头、返回纸团、飞进房间或先明显向右飞。

### 4. 振翅与持续夜间状态

- 翅膀要有可辨认的展开、抬起、下压动作，慢而自然。
- 用户反复强调：**放慢的是振翅频率，不是飞行位移，也不是整段视频。**
- 不要通过统一降低播放速度来声称已经独立放慢了振翅。
- 起飞动画结束后，鸟不能突然消失；保留朝窗外飞行的姿态，持续缓慢振翅。
- 字幕出现时，振翅不能暂停、卡顿、跳帧或重播。
- 不应为循环而倒放飞行，造成鸟掉头或返回。
- 后来试过5.6秒一轮振翅，这是实现参数，不是用户确认的硬性数值；应以实际观感足够缓慢、自然为准。

### 5. 丝线关系

- 丝线是由鸟牵拉出来的，一端在源纸团折痕处，另一端连着鸟尾。
- 随鸟前进，丝线逐渐被拉长，并始终连续连接。
- 不得提前展示整条飞行轨迹，不得凭空漂浮、断开、分叉或成为无关装饰曲线。
- 要细、轻、克制；不能做成几根粗白线、激光束或抢眼的光带。
- 用户批评白线效果，并不等于取消“鸟牵着细丝”的设定。

### 6. 字幕和开灯返回

- 点击开关时先隐藏旧字幕。
- 按用户后续明确的要求，在动画接近结束时，新字幕自然淡入。
- 字幕只改变文字的显示，不能重置、替换或暂停鸟的动画。
- 关灯转开灯也必须自然，开关状态、灯光、人物动作和文字对应。
- 两个方向都不能夹入错误状态的单帧：尤其不能在夜间动画结束后闪出一帧白天。

## 五、质量要求和已失败的做法

必须避免：

- 静态图片淡入淡出冒充人物关灯、趴下等连续动作。
- 纸团变形、漂移或随着鸟一起飞走。
- 地面畸形大鸟、重复鸟、突然出现的第二批鸟。
- 粗糙 SVG 鸟形替代早期精细羽翼。
- 通过模糊和压暗把鸟变成模糊光团。
- 裁切过小、帧数不足造成羽翼细节丢失和动作跳变。
- 局部矩形补丁造成明显色差、接缝、重影或纸团错位。
- 修振翅时顺带把整段飞行减速。
- 反复只打开新版本、汇报“已修好”，却没有验证实际画面。

用户要求：发现半成品或明显缺陷就继续修，不要把中间结果当完成交付。生成完成、下载完成、代码接入和视觉验收是不同阶段，汇报必须区分。
