## 后续同步约定

- 项目任务完成时，检查工作区和远端变更，提交本次相关文件并推送。
- 新增或阅读使用的项目资料，应更新归档清单并纳入版本控制。
- 原始课件和文字提取稿均保存；原始资料与项目自行编写内容区分来源。
- 不同步账号凭据、访问令牌、`.env`、依赖目录、构建缓存或与项目无关的系统内部指令。
- Git 只能同步已保存并提交的文件，不会自动归档聊天全文，也不会自行持续运行。
- 不创建后台定时任务，不执行强制推送，遇到远端冲突时保留并解决冲突。
- 推送完成后核对本地提交与远端分支是否一致。不能将“已提交到本地”表述为“已上传 GitHub”。

## 手动同步参考

远端配置成功后，可在项目目录检查并执行：

```powershell
git status
git fetch origin
git add <本次需要同步的文件>
git commit -m "说明本次修改"
git push
```

具体分支名与远端名称以成功建立的配置为准。
