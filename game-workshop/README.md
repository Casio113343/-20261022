# 造游工坊

多类型游戏生成平台，采用后端先行的开发顺序。

- [后端启动与接口](./backend/README.md)
- [前端需求规格](../docs/游戏生成平台前端需求规格.md)

后端已具备分类、资料保存、方案整理和版本确认流程，通过真实PostgreSQL集成测试。用户已选择先做本地模板版，后续再接AI服务。前端已接通创作、制作、美术版本和图形原型试玩流程，详见 [前端运行说明](./frontend/README.md)。真实图片模型尚未接入，完整自由生成游戏仍待后续实现。

后端美术状态、局部编辑和素材复用的当前实现见 [美术任务与版本机制](../docs/后端美术任务与版本机制.md)。真实图片服务尚未接入。

本轮验证见 [后端美术机制验证记录](../docs/后端美术机制验证记录.md)。
